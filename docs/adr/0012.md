# ADR 0012：以项目为入口，不以编辑器为中心

- 状态：已接受
- 日期：2026-10-16
- 修订：[ADR 0003](0003.md)、[ADR 0005](0005.md)

## 决策

入口是项目或文件夹。没有打开项目时显示 Welcome（最近项目、打开文件夹、有 agent 会话的文件夹）；打开后进入项目主页，首先看到这个项目里待审的 agent 会话、运行中的 agent 和会话外的改动。

审阅一个会话时按轮次读「prompt → agent 说明 → 改动」，文件只作为进度列表。代码上下文（调用方、相关测试、改动历史）在 Diff 里点符号后从抽屉呼出。

界面分三层：

| 层 | 内容 |
|---|---|
| 常驻 | 项目侧栏、项目主页、审阅（会话简报 + 改动叙事）、已看进度、审阅意见发送栏 |
| 按需呼出 | 上下文抽屉、与 agent 对话、⌘K、并行总览、Files |
| 收起 | 完整文件阅读、编辑、终端原始输出 |

不做：活动栏、文件标签页、常驻文件树、状态栏、底部终端停靠；不显示编辑器、索引、语言服务器状态；不显示「生效的 agent 指令」。

## 影响

- 视图 crate 改为 `welcome`、`project_home`、`review_view`、`context_drawer`、`conversation`、`worktrees`、`file_reader`。
- 文件浏览与编辑的优先级下调到 P2；P1 交付打开项目、项目主页、按轮次审阅和审阅意见回传。
- 行评论改为「审阅意见」：先攒成一批，再带文件与行号一次发回会话。
