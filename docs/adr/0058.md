# ADR 0058：`terminal/input` 由预算 ≤ 2 µs 改为只记录，目标 ≤ 6 µs；`terminal/open` 改为 ≤ 150 µs

- 状态：已接受
- 日期：2026-10-31
- 修订：[terminal 设计「性能」](../design/terminal.md#性能)（`terminal/input`、`terminal/open` 的预算）

## 背景

[terminal 设计](../design/terminal.md)给 `terminal/input` 的份额是中位数 ≤ 2 µs：主线程上的一次 `Terminals::input`，即把输入放进队列、向终端线程的唤醒 socket 写一个字节。这个数在设计阶段没有测过。第 3 步实现了被测的代码，按设计的做法（终端线程 `poll` 主端 fd 和唤醒 socket，空闲时无限期阻塞），本机（Apple M5 Pro、macOS 27.0.1）的实测：

- `terminal/input`：中位数 3.6–3.9 µs（多次运行；安静时有过两次 1.5、1.7 µs，之后没有再出现）。
- 其中主要是唤醒的代价，不是本 crate 的其他工作。对照（一个线程睡在 `poll` 上，另一个线程写一个字节，每次之间睡 200 µs 让它重新睡下）：socketpair 中位数 3.1–3.8 µs（p95 5.3–7.3 µs），pipe 2.3–2.8 µs，`kqueue` 的 `EVFILT_USER` 触发 1.9–2.0 µs。没有线程在等时，同一次 socket 写只要 0.33 µs。入队、查表、`Arc` 克隆合起来不到 1 µs。

托管 runner 上这个数不稳定：#338 的终端代码相同的两个提交，CI 上分别是 9.67、8.29 µs 和 21.2、18 µs，翻了一倍。所以任何一个固定的数在托管 runner 上都不能判定回归。

这一项不是 [ADR 0055](0055.md) 的放宽：0055 针对「没有改动被测代码的 PR 上反复超标的份额预算」，而这个 PR 引入了被测的代码。

## 决策

- `terminal/input` 不再判定，只记录。目标是开发机上中位数 ≤ 6 µs（本机实测最差约 3.9 µs），写在 terminal 设计里，不进 CI。
- 输入路径的回归由 `terminal/echo_latency`（中位数 ≤ 1 ms，p95 ≤ 3 ms）判定，它含同样的一次唤醒，CI 上是 103 µs 量级。
- `terminal/open` 由中位数 ≤ 100 µs 改为 ≤ 150 µs。本机 55–69 µs，#338 的 CI 上 77.5、94.7、108 µs（代码相同或几乎相同）；150 µs 比最差的 108 µs 留约 40% 的余量。这一项继续判定：它有明显的留余，而且走的不是睡眠唤醒的路径。
- 放弃的方案：
  - 继续放宽托管 runner 上的数：#338 上 6 µs、12 µs 都在下一次运行里超标。
  - 作为判定机器的条目（[ADR 0052](0052.md)）：那些条目都以首帧结束，判定机器的运行也不测这类微基准；为一个主线程上微秒级的开销不值得改变它的含义。
- 保持设计的做法：终端线程 `poll` 主端 fd 和唤醒 socket。放弃的方案：
  - 唤醒改用 pipe：约 2.5 µs，仍然超过 2 µs，只省 1 µs。
  - 改用 `kqueue` 加 `EVFILT_USER`：约 1.9 µs，加上入队的不到 1 µs 仍不保证 ≤ 2 µs，而且要改设计里「数据流与线程」的 `poll` 循环和唤醒 socket。
  - 让终端线程在输入之后自旋一小段时间，使连续的输入不必唤醒：只对连续输入有效，每次打字停顿之后的第一个输入仍要唤醒，而且空闲时烧 CPU（性能是第一约束）。

## 影响

- `lectern-bench` 的 `budgets.rs`：`terminal/input` 改为只记录，`terminal/open` 的 `Limit::TimeAtMost`。
- [terminal 设计](../design/terminal.md)「性能」的基准表、「实际验证」「与设计的差异」；[bench 设计](../design/bench.md)的预算表。
- 帧、回显和启动的预算不变（`terminal/echo_latency` 实测中位数 80–160 µs，含同样的一次唤醒）。

## 已知限制

- 这一项单独的回归（例如入队变慢几微秒）CI 不会拦下，要看报告里的记录值。
- 本机上，睡着的线程落在哪个核、核是否在深度空闲，会让同一台机器上的数在 1.5 µs 到 3.9 µs 之间变化。
