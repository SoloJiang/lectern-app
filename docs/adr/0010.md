# ADR 0010：架构完全可插拔

- 状态：已接受，已被 [ADR 0018](0018.md) 修订
- 日期：2026-10-16

## 决策

参考 DeepSeek Harness：kernel crate 只负责插件装载、服务依赖和生命周期，审阅台、终端、语言支持、会话来源等功能全部是插件。内置插件编译期链接、按需激活；第三方插件以独立进程（stdio JSON-RPC）接入，用 Seatbelt 沙箱。

## 影响

插件边界即任务边界；插件之间禁止直接依赖；每个插件有激活耗时与常驻内存预算。
