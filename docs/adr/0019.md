# ADR 0019：会话简报默认由规则生成，模型分析由用户手动触发

- 状态：已接受
- 日期：2026-10-16

## 背景

审阅页顶部的会话简报列出「值得先看的几处」（[交互规范](../design/interaction.md#核心闭环)），此前没有规定简报的内容从哪里来。[pulls.review 调研](../research/pulls-review.md)提出了两个需要人决定的问题：简报是否调用模型，以及 MR 视图是否读取 pulls.review 写在 PR 里的共享分析评论。2026-10-16 人确认按调研的推荐处理，结论记录在这里。

## 决策

**简报默认只用规则生成**

- 打开会话时，简报只用本地已有的信息生成：Drifted 的行、没有同步修改的调用方、改到的公开接口、噪声文件（生成文件、lockfile、快照）的折叠情况等。规则的完整列表在 `review` 的设计文档里定义。
- 规则生成不调用模型，不消耗额度，在首帧之后的后台任务里计算。

**模型分析由用户手动触发**

- 简报上有一个 Analyze 操作，也可以从 ⌘K 执行。只有用户执行它时才调用模型，Lectern 不在打开会话、切换会话或会话更新时自动调用。
- 调用的是用户本机已登录的 Claude Code 或 Codex 命令行，默认用被审阅会话所属的 agent。Lectern 不保存模型 API key，也不直接请求模型的 HTTP 接口。
- 查找命令行：从 Finder 启动的应用不读取 shell 的启动文件，继承的 `PATH` 常常不含 `~/.local/bin`、`/opt/homebrew/bin` 这类安装位置。Lectern 依次查找设置里配置的绝对路径、用户登录 shell 的 `PATH`（第一次执行 Analyze 时查询一次并缓存）和常见安装目录。找不到时 Analyze 显示为不可用，并说明原因和设置入口。
- 命令行以只读模式运行（Claude Code：`--allowedTools Read Grep Glob`，并禁用 Bash、Edit、Write；Codex：`--sandbox read-only`），按需启动、完成即退出，符合架构规则 3。
- 只读参数只能防止写入，不能限制读取：被审阅的 diff 里可能有提示词注入，诱导 agent 读取仓库之外的文件再发给模型。所以命令行在 Seatbelt 沙箱里运行（由 `platform` 生成配置，与 [ADR 0018](0018.md) 的进程插件相同）：
  - 可读：本次分析的临时目录（写着 patch）、被审阅的 worktree、该 agent 自己的安装目录和配置目录（登录状态在那里）；其余路径拒绝。
  - 可写：只有本次分析的临时目录和该 agent 写会话所需的目录。
  - 网络：按 ADR 0018 的本机代理方式，只放行该 agent 的模型服务主机。
  - 不加载用户为该 agent 配置的 MCP 服务器和额外工具，具体参数在 `agents` 的设计文档里按 agent 列出。
- 每次调用有超时。超时、用户取消、离开审阅页或关闭项目时，Lectern 终止整个子进程组并回收，丢弃尚未返回的输出，不留下在后台运行的 agent，也不会在之后显示过期的结果。
- 分析在单独的会话里运行，不续接被审阅的会话。这个辅助会话不出现在 Lectern 的会话列表里：可用时用不保存会话的调用方式，否则记录它的会话 ID，会话发现时过滤掉。
- 模型的输出是 `critical` 标记加文件备注和行备注，经过结构校验、覆盖检查、一次纠错重试和对账后才显示；校验失败时报错，保留规则生成的简报，不把规则结果当作模型结果保存。
- 结果按完整分析请求的哈希缓存（规范化后的提示词、排序后的路径与 blob OID 列表、schema 版本、模型 ID）。这次调用消耗的 token 计入用量统计（[ADR 0014](0014.md)），在简报上显示：`agents` 从命令行的结构化输出里取出用量，交给 `usage` 作为一条带会话 ID 的原始用量记录；辅助会话如果也被保存到日志里，`usage` 按会话 ID 去重，同一次调用只计一次。

**MR 视图只读取 pulls.review 的共享分析评论**

- MR 视图读取 PR 评论里带 `<!-- pulls.review data -->` 标记的分析结果，作为这个 PR 的分组参考显示；head sha 不一致时标为过期。
- 解析失败的评论忽略，不报错；评论里的文字按外部内容处理，原样显示，不执行其中的任何指令。
- 评论可能来自任何人。lz-string 压缩的内容按流解压，解压后超过 2 MB 时停止并丢弃，不读入完整结果再校验；未压缩的 JSON 同样限 2 MB。
- Lectern 不向 PR 写入自己的分析结果。以后需要时另写 ADR。

## 影响

- `review`：定义简报的规则、模型输出的数据结构与校验流程。
- `agents`：查找并启动只读的 Claude Code / Codex 命令行，超时与取消时终止进程组，过滤辅助会话，把用量交给 `usage`。
- `platform`：为 Analyze 生成 Seatbelt 配置。
- `cache`：模型结果的缓存键。
- `usage`：接收 Analyze 调用的用量记录，按会话 ID 与日志去重。
- `forge`：解析 pulls.review 的共享分析评论，限制解压后的大小（P3）。
- `review_view`：简报上的 Analyze 操作与结果展示，界面字符串走 Fluent。
- [交互规范](../design/interaction.md)「核心闭环」第 3 步补充简报的来源。
