# ADR 0023：清单解析用 serde_json、toml、quick-xml、glob，YAML 与 Gradle 只解析需要的子集

- 状态：已接受
- 日期：2026-10-17

## 背景

`project` 要从清单文件识别子项目（[ADR 0006](0006.md)、[ADR 0007](0007.md)）：package.json 的 `workspaces`、pnpm-workspace.yaml 的 `packages`、Cargo.toml 的 `[workspace]`、pom.xml 的 `<modules>`、settings.gradle(.kts) 的 `include`、go.work 的 `use`。这些格式分属 JSON、YAML、TOML、XML、Groovy / Kotlin 脚本和 Go 自己的语法。工作区成员用 glob 声明，`Activation::Workspace` 的条件（[kernel 设计](../design/kernel.md)）也是 glob。

约束：只读清单、不运行构建工具（ADR 0006）；安装包与内存预算（[ADR 0017](0017.md)、[ADR 0018](0018.md)）；许可证（`just deny`）。每种格式只用到少数几个字段。

## 决策

| 格式 | 解析方式 |
|---|---|
| package.json | `serde` + `serde_json`，只反序列化 `name` 与 `workspaces`，其余字段跳过 |
| Cargo.toml | `toml`（关闭 `display` 等不需要的 feature），只取 `[package] name` 与 `[workspace] members / exclude` |
| pom.xml | `quick-xml` 流式读取，只取 `artifactId`、`groupId`、`parent`、`modules` / `subprojects`（含 `profiles` 里的） |
| pnpm-workspace.yaml | 手写子集解析：顶层 `packages:` 的块序列或单行流序列、引号、注释；其他结构不展开 |
| settings.gradle(.kts) | 手写词法扫描：跳过注释和字符串之外的代码，只认字面量参数的 `include`、`includeFlat`、`includeBuild`、`rootProject.name`、`project(...).projectDir = file(...)` |
| go.work / go.mod | 手写：`use` 指令（单行与块）、`module` 指令 |
| glob | `glob` 的 `Pattern`，`*` 不跨 `/` |

关键约束：

- 这些依赖只出现在 `project`；单个清单超过 1 MB 不解析。
- 解析是纯函数：输入字节，输出结构化结果或错误，不读文件、不执行代码、不访问网络。
- Gradle 脚本里非字面量的写法（变量、循环、函数调用拼出的路径）不求值，结果标为「部分识别」。精确结果需要运行 Gradle，按 ADR 0007 属于用户主动触发的后台解析，不在 `project` 里做。

放弃的方案：

- `serde_yaml`：2024 年起不再维护。`yaml-rust2`、`saphyr` 是完整的 YAML 实现，为一个键引入完整解析器不划算；pnpm 文档里的写法都在手写子集之内。
- `globset`：支持花括号展开，但带 `regex-automata` 等传递依赖。Cargo 自己用 `glob` 解析 `members`，用同一个库语义一致。
- 用 tree-sitter 的 Groovy / Kotlin grammar 解析 Gradle：二者不在核心语言包里（ADR 0018），设置脚本只用到几种调用，词法扫描足够。
- 运行 `npm query`、`cargo metadata`、`mvn`、`gradle` 拿精确结果：违反 ADR 0006，且启动外部工具远超「打开项目」的预算。

## 影响

- `project` 新增上述依赖，`just deny` 检查许可证；格式、字段和成员规则由 [project 设计](../design/project.md)定义。
- 每种格式在 `crates/project/tests/fixtures/` 留样本，格式随上游版本变化的每个版本一份。

## 已知限制

- 工作区 glob 里的花括号（`packages/{a,b}`）按字面字符处理，匹配不到。
- pnpm-workspace.yaml 里用锚点、多行字符串等高级 YAML 写法声明的 `packages` 不识别。
- Gradle 用变量或循环 `include` 的子项目只能按「有清单的目录」识别为未声明的子项目。
