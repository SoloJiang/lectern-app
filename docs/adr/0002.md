# ADR 0002：终端只接入 Ghostty 内核（libghostty-vt）

- 状态：已接受
- 日期：2026-10-16

## 决策

「连接 Ghostty」指用 libghostty-vt 做终端状态机，在 GPUI 里自绘字符网格。不嵌入 Ghostty 渲染器，不使用 gpui-libghostty，也不使用 alacritty_terminal。

## 影响

终端的选区、搜索、链接识别、浮层与其他视图一致；PTY、渲染和交互需要自建。libghostty 未打版本，用 libghostty-rs 的 vendored 构建锁定源码，构建链需要 Zig。
