# ADR 0013：界面英文优先，支持简体中文

- 状态：已接受，字体一项已被 [ADR 0015](0015.md) 修订
- 日期：2026-10-16

## 决策

- 界面默认英文；首次启动跟随系统语言，简体中文系统显示中文。设置里切换，立即生效。
- 人和 agent 写的内容（prompt、说明、评论）原样显示，不翻译；代码、路径、命令、快捷键不翻译。
- 文案用 Fluent（`fluent-rs`）资源文件管理，放在 `i18n` crate；CI 检查 en 与 zh-CN 的键一致。
- 先按英文排版，再用中文验证；按钮不定宽，关键标签不截断。
- ~~字体：IBM Plex Sans，中文回退 PingFang SC；代码用 IBM Plex Mono。~~ 已被 [ADR 0015](0015.md) 修订：SF Pro / SF Mono，中文回退苹方。

## 影响

- P0 增加 i18n 基础设施；所有界面字符串从第一天起走资源文件，不允许硬编码。
- README 与仓库简介以英文为主，另提供中文版。
