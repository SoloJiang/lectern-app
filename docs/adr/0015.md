# ADR 0015：macOS 原生视觉与动效标准

- 状态：已接受
- 日期：2026-10-16

## 决策

Lectern 的界面按 macOS 自带应用的标准设计，目标是安静、跟手。

- **字体与颜色**：SF Pro / SF Mono，中文回退苹方；使用系统语义色，强调色跟随系统设置；浅色 / 深色跟随系统，不做自有主题。
- **窗口结构**：半透明侧栏、带副标题的工具栏、右侧检查器、浮动面板、底部浮条；只用系统控件（分段控件、开关、圆形勾选、按钮），不自造控件。
- **层级**：靠留白和圆角分组列表区分，分隔线 0.5pt；状态用圆点或一行次要文字表达，不用彩色标签块。
- **动效**：每个动作有短而可中断的动画，时长与曲线以 [交互规范「动效」](../design/interaction.md#动效) 一节为准。动画只改位移、透明度和裁剪，稳定 120 fps；操作结果先生效，写盘在后台；系统开启「减弱动态效果」时，位移改为淡入淡出。

本决策取代交互设计初稿中的自定义深色主题（IBM Plex 字体、黄铜强调色）。

## 影响

- `ui` crate 提供的 token 映射到系统语义色和系统强调色，不写死颜色值；agent 标识色是唯一的自定义颜色，浅色 / 深色各一组，已通过色觉辨识校验。
- `ui` crate 提供统一的动画原语（滑入面板、勾选、进度、展开、分段滑块、开关），曲线和时长集中定义，视图不各自写动画参数。
- UI 探针与 bench 增加检查项：动画期间帧时间不超过 8.3ms；开启减弱动态效果时没有位移动画。
