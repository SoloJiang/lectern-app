# 交互规范

Lectern 以审阅为中心：打开项目，先看 agent 改了什么。入口是项目或文件夹；打开后进入项目主页，首先看到这个项目里待审的 agent 会话；审阅时按轮次读「改动叙事」。代码、对话、编辑都按需呼出，不常驻。

交互设计画布（含可点击的审阅原型）：https://claude.ai/artifact/LVSXNi9xPviRgzdycnskp9 。决策记录见 [ADR 0012](../adr/0012.md)、[ADR 0013](../adr/0013.md)。

## 核心闭环

1. **Open folder**：打开任意文件夹或仓库。
2. **Project home**：看这个项目里待审的会话、运行中的 agent、会话外的改动。
3. **Review**：顶部是会话简报（值得先看的几处），下面按轮次读 prompt、agent 说明和改动。简报默认由规则生成；执行 Analyze 才调用本机的 Claude Code 或 Codex 做补充分析（[ADR 0019](../adr/0019.md)）。
4. 改动无误：**Looks good**，全部标记已看，进入提交或开 MR（GitHub / GitLab）。
5. 改动有问题：在行上写 **Review notes**，汇总成一批后用 ⌘↩ 发回会话；agent 的修改作为新一轮出现，回到第 3 步只看新轮次。

## 三层结构

| 层 | 内容 | 规则 |
|---|---|---|
| 常驻 | Project sidebar（Overview、Sessions、Packages）、Project home、Review（会话简报 + 改动叙事）、Progress、Review notes 发送栏 | 打开就看得到，占据主要空间 |
| 按需呼出 | Context drawer（调用方、测试、历史）、Conversation（⌘\）、⌘K、Worktrees、Files、Usage | 从当前视图触发，Esc 回到原处 |
| 收起 | 完整文件阅读（⇧⌘O）、编辑（Edit… / ⌘E）、终端原始输出（Conversation 的 Terminal 页） | 存在，但不出现在默认界面 |

不做的 IDE 元素：活动栏、文件标签页、常驻文件树、状态栏、底部终端停靠、编辑器 / 索引 / 语言服务器状态、生效的 agent 指令。

| 04 | Worktrees | 分组列表 Active / Idle，每行显示分支的累计 token（有 MR 时为 MR 用量）；右侧检查器显示分支用量，对比所选 worktree 与 main，并提示与其他 worktree 是否有文件重叠 |
| 05 | Usage | 额度卡片（Codex 来自日志，Claude Code 来自 statusline）；每日 token 柱状图；当前项目：项目合计、按分支明细（P3 起按 MR，未开 MR 的分支一并列出；「不属于任何 MR」单独一行）和按模型明细（普通文件夹没有分支明细，按模型明细照常显示）；所有项目：各项目合计与占比，加上「其他」一行（还没有打开对应项目的用量）；标为「路径已不存在」的项目行有「合并到…」操作（行尾按钮与右键菜单），在弹出的列表里选择现在的项目，确认后以前的用量并入它，合并过的行显示「已合并」并可以撤销；同一路径上身份无法确定、暂列为临时项目的行（根提交或主远端地址变了，又没有代码平台的仓库 ID）有「是同一个项目」和「是新项目」两个确认操作，同样可以撤销；7D / 14D / 30D；只显示 token，不显示费用 |
| 06 | Merge Request（P3） | MR 的累计 token，编写与审阅分开，按会话列出明细；PR 里 pulls.review 的共享分析标为「可能过期」，只用来给文件分组，未验证作者的分析折叠；按共享分析分组的文件列表和审阅入口 |

| ⌘↩ | 把待发送的审阅意见发给 agent |
| Space | 光标在符号上时打开上下文面板 |
| ⌥⌘I · ⌘\ | 显示检查器 · 切到 Conversation |
| ⇧⌘O · ⌘E | 打开完整文件 · 编辑 |
| ⌘[ · ⌘] | 完整文件阅读里后退 · 前进到最近的阅读位置；退到最早的位置之后，⌘[ 回到打开它的视图。编辑时这两个键是减少 · 增加缩进，后退 · 前进不可用（[file_reader 设计](file_reader.md#action-与快捷键)） |

## 语言

- 默认英文；首次启动跟随系统语言，简体中文系统显示中文。在设置里切换语言，立即生效。
- 人和 agent 写的内容（prompt、说明、评论）原样显示，不翻译。代码、路径、命令、快捷键不翻译。
- 先按英文排版，再用中文验证；按钮不定宽，关键标签不截断。
- 相对时间、数量、复数按语言格式化（`2/6 reviewed` ↔ `已看 2/6`）。
- 文案集中在 Fluent（.ftl）资源文件，CI 检查 en 与 zh-CN 的键一致。
- 字体：系统字体 SF Pro，中文回退苹方；代码用 SF Mono（[ADR 0015](../adr/0015.md)）。

## 用量

用量按项目和 MR 两级统计（[ADR 0014](../adr/0014.md)、[ADR 0020](../adr/0020.md)）：项目合计按 7 / 14 / 30 天的时间窗口统计；一个 MR 由哪些会话、哪些轮次完成，就把它们的 token 加在一起，还没开 MR 的按分支统计。项目侧栏底部的 Usage 入口显示本项目最近 7 天的合计。并行 worktree 列表和检查器显示当前分支的累计 token（P1 称为分支用量，关联到 MR 后称为 MR 用量）；会话简报为本会话改到的每个分支各显示一行累计 token 和本会话的占比，关联到 MR 后每个 MR 一行（一个分支同时对应几个 MR 时各占一行，注明共用的分支）；每轮标题显示该轮 token，作为最细的明细；会话卡片不显示 token。Conversation 显示上下文窗口占用，Usage 入口同时带最紧张的额度窗口进度条。Lectern 不估算费用，只显示 token 和额度百分比（[ADR 0022](../adr/0022.md)）。

## 状态与异常

| 状态 | 处理 |
|---|---|
| 项目里还没有会话 | 会话按 cwd 匹配到项目；没有时主页显示最近提交和 New session |
| 加载 | 100 ms 内不显示加载态；100 ms – 1 s 显示骨架；超过 1 s 显示进度并可取消 |
| 已漂移 | 会话结束后代码又被改过：无法对齐的改动块不显示归因，不做猜测 |
| 会话格式无法识别 | 降级为按文件显示，隐藏轮次和说明，不弹错误 |
| 与 agent 同时改了文件 | 只在你编辑过的文件上提示三方合并，不自动覆盖任何一方 |
| Agent 请求权限 | 出现在 Conversation 里；面板关着时，项目侧栏里对应会话显示等待标记 |
| 大文件 | 完整文件阅读照常打开任意大小的文件；二进制、不是 UTF-8 或解析过慢时显示纯文本，不提示。超过编辑上限（1 MiB，或有超过 4 KiB 的行）时 Edit… / ⌘E 不可用，悬停说明原因（[ADR 0034](../adr/0034.md)） |
| 跳转到依赖 | 候选来自依赖时，次要文字显示包名和版本（如 `react 19.3.1`）；⌘K 不搜索依赖里的符号（[ADR 0033](../adr/0033.md)） |

## 视觉

按 macOS 原生应用的标准设计（[ADR 0015](../adr/0015.md)）：系统字体、系统颜色、标准窗口结构，层级用留白和分组表达。

| 项 | 规格 |
|---|---|
| 字体 | SF Pro，中文回退苹方；字号用 macOS 的文字样式（下表），不自定其他字号；代码 SF Mono 12pt |
| 颜色 | 系统语义色（label、secondaryLabel、separator、controlBackground 等）；强调色跟随系统设置；浅色 / 深色跟随系统，不做自有主题 |
| agent 标识 | 8pt 圆点（卡片、侧栏、Welcome 都是 8pt）：Claude Code 橙（浅 `#D9790A` / 深 `#C77A1A`），Codex 靛（浅 `#5856D6` / 深 `#6260D8`），两种模式都通过色觉辨识校验 |
| 分组 | 圆角 12pt 的分组列表（卡片）放在页面底色（`under_page_background`）上，卡片用分组色（`control_background`）和 0.5pt 描边（`separator`），所以卡片和页面有边界；行之间是 0.5pt 分隔线，从文字起点开始；状态用圆点或一行次要文字表达（状态词可以用语义色的文字），不用彩色标签块 |
| Diff | 增删行用系统绿 / 红的淡底色，并带 `+` / `−` 符号，不只靠颜色区分 |
| 控件 | 只用系统控件：分段控件、开关、圆形勾选、按钮（高 24–30pt）。一个区域里至多一个主色（强调色填充）按钮；工具栏里的控件是 28pt 的图标按钮或次要按钮，不用文字链接代替图标 |

文字样式（macOS 人机界面指南的层级；`ui` 的 `TextRole` 按此列出，名字和字重由 [ui 设计](ui.md)定）：

| 样式 | 字号 | 用在 |
|---|---|---|
| Large Title | 26pt，粗体 | 屏幕的大标题：项目主页的一句话标题、Welcome 的应用名 |
| Title 1 | 22pt，粗体 | 审阅页阅读栏顶部的会话标题 |
| Title 2 | 17pt，中等 | 审阅里每一轮的 prompt |
| Title 3 | 15pt | 大标题下面的一句说明（次要色）、上下文面板的标题（半粗） |
| Headline | 13pt，半粗 | 工具栏标题、分组标题、卡片和行的标题 |
| Body | 13pt | 正文、侧栏和列表里的普通文字 |
| Callout | 12pt | 行里的次要文字、统计行、按钮旁的说明 |
| Subheadline | 11pt | 工具栏副标题、侧栏分区小标题（半粗）、检查器里的 `Turn N` |
| Footnote | 10pt | 备注（目前没有用处） |

画布用的字号按下面映射到样式：22px 是 Title 1；17px、字重 500 是 Title 2；15px 是 Title 3；13px 半粗是 Headline；12px 是 Callout；11px 是 Subheadline。画布上不是系统字号的两处：Welcome 的应用名 30px 取 Large Title（26pt）；审阅里 agent 说明的 14px 离 Body 与 Title 3 各差 1pt，取 Body（次要色）。

画布内部不一致、本文做了取舍的地方：

- **阅读栏宽度**：Overview 画板 820pt，Flows 画板和 Review 画板 760pt。取 760pt。
- **大标题字号**：Flows 画板的说明文字写「大标题 40」，Overview 画板的大标题画的是 26px，Welcome 画的是 30px。40pt 不是系统字号，取 Large Title 的 26pt。
- **agent 圆点**：Overview 画板的会话卡片画了 10px，侧栏和 Welcome 画了 8px。取 8pt。
- **上下文面板**：Review 画板画了 420pt、内缩 8pt。产品负责人 2026-10-29 改为按画布（见上表 Panel）。
- **简报条目的标记**：Review 画板画了 16px 的彩色图标，Flows 画板写「状态用一个小圆点或一行灰字」。取圆点（[review_view 设计「界面」](review_view.md#界面)）。

## 动效

动画只用于表达元素的来源和去向。下表是实现标准，交互设计画布的 03 画板是可点击的参考。

| 交互 | 动画 | 时长与曲线 |
|---|---|---|
| 打开上下文面板 | 从右侧滑入；阅读栏不动、不加遮罩 | 380ms · `cubic-bezier(0.32, 0.72, 0, 1)` |
| 关闭面板 | 原路滑出 | 280ms · 同上 |
| 进入会话 | 列表行的标题平移、放大成审阅页标题，其余内容淡入 | spring · response 0.35 · damping 0.86 |
| 勾选已看 | 圆圈填色，对勾描出；文件名变为次要色 | 180ms 填色 · 220ms 对勾，延迟 60ms |
| 已看进度 | 进度条宽度增长 | 360ms · `cubic-bezier(0.32, 0.72, 0, 1)` |
| V：已看并下一个 | 勾选动画结束后，阅读栏滚到下一个文件顶部 | 滚动 300ms · ease-out |
| 展开评论框 | 在当前行下方撑开，内容淡入，下方代码平滑下移 | 280ms 高度 · 200ms 透明度 |
| 分段控件 | 滑块平移到新选项 | 260ms · `cubic-bezier(0.32, 0.72, 0, 1)` |
| 开关 | 滑钮移动，末端轻微回弹 | 240ms · `cubic-bezier(0.34, 1.3, 0.64, 1)` |
| Agent 新一轮到达 | 新轮次从下方 8pt 淡入；侧栏会话行的圆点轻闪一次 | 240ms · ease-out |
| 悬停 | 背景淡入，离开时稍慢 | 进入 120ms · 离开 200ms |

规则：

- **随时可打断**：动画进行中再次操作时，从当前位置继续过渡，不排队、不跳回起点。键盘和鼠标触发同一套动画。
- **界面先更新**：勾选、加意见、切换会话立刻生效，写盘在后台进行。100ms 内完成的操作不出现加载态。
- **只改低开销属性**：动画只改位移、透明度和裁剪，不触发重排，保持 120 fps。
- **减弱动态效果**：系统开启该选项时，位移改为淡入淡出，时长减半。
