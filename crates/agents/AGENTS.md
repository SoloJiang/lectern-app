# agents（`lectern-agents`）

Claude Code / Codex 会话发现与解析，按 cwd 归位到项目和 worktree；P3 起包含 ACP 客户端。

- 层：领域层。可以依赖领域、基础设施和 kernel 层；不得直接或间接依赖 GPUI（架构规则 2）。
- 设计文档：`docs/design/agents.md`，尚未编写。先按[模板](../../docs/design/TEMPLATE.md)编写，设计文档 PR 合并后再写代码。
- issue：[#13](https://github.com/SoloJiang/lectern-app/issues/13)、[#23](https://github.com/SoloJiang/lectern-app/issues/23)
- ADR：[0012](../../docs/adr/0012.md)、[0014](../../docs/adr/0014.md)、[0019](../../docs/adr/0019.md)

## 边界

- 会话 JSONL 流式读取、增量解析，不整文件读入内存。
- 格式随 agent 版本变化：每个版本在 fixtures 里留一份脱敏样本，遇到不认识的记录跳过并计数，不报错退出。
- token 统计在 `usage`，本 crate 只交出原始用量记录。
- Analyze 调用的 Claude Code / Codex 命令行以只读方式运行（[ADR 0019](../../docs/adr/0019.md)；Claude Code 只开放读文件的工具；Codex 关闭它自己的沙箱（`--sandbox danger-full-access`，审批 `never`），只读和断网由外层 Seatbelt 保证，因为它的 `read-only` 模式要嵌套调用 `sandbox-exec`；快照不是 git 仓库，Codex 需要 `--skip-git-repo-check`），按需启动、完成即退出。agent 经监护进程启动：Lectern 可执行文件的监护模式，只在分析期间存在，与 Lectern 之间保持管道，Lectern 崩溃时读到 EOF、截止时间到了或 30 秒没有心跳时，按沙箱特征终止全部成员；发信号前按 PID 加启动时间重新核对身份和沙箱成员；Lectern 启动时再按残留临时目录的沙箱特征扫描一次。命令行在 `platform` 生成的 Seatbelt 沙箱里运行，只能读取本次分析的输入、被审阅版本的只读快照（从被审阅的提交树生成，只含受跟踪文件和本次改动的文件）和该 agent 解析后的可执行文件及其依赖闭包（版本目录或包目录，不是 `~/bin` 这类公共目录），不加载用户的其他配置和 MCP 服务器。真实凭据不进入沙箱、环境变量或参数：命令行的模型服务地址指向本 crate 在回环地址上提供的凭据转发端点，只拿到占位令牌，端点在沙箱外换上真实凭据再转发到该 agent 的模型服务主机，只允许该 agent 推理接口的方法、路径和这次配置的模型，请求体按适配器模板逐层检查，安全与计费相关字段必须等于模板值（流式、`store: false`、无 `background`、工具和 `include` 只取模板值），未知字段和取值拒绝，同一次分析同时只处理一个请求，不排队（并发的请求直接返回 429，不读请求体；最多 4 个连接，请求头上限 64 KB，空闲 30 秒关闭），转发前检查并计入轮数与 token 预算（请求体上限 4 MB，输入 token 用模型服务的计数接口或按字节数上界估计），按剩余预算改写输出上限；命令行不支持设置服务地址时这个 agent 的 Analyze 不可用；模型服务配置按白名单传入；每次分析有轮数和 token 上限（ADR 0019）。每次调用有超时（默认 10 分钟，也是 CPU 消耗的硬上界），超时、取消或关闭项目时终止全部跟踪中的子孙进程并回收，丢弃未返回的输出。它产生的辅助会话不出现在会话列表里：可用时用不保存会话的调用方式，否则记录会话 ID 并在会话发现时过滤。
- 查找命令行时依次用设置里的绝对路径、登录 shell 的 `PATH`（查询一次并缓存；查询经监护进程启动，限时 5 秒，输出各最多 64 KB，超限终止全部子孙进程，只取随机标记之间的内容）和常见安装目录；找不到时返回明确的不可用状态，界面据此提示。
- Analyze 的工作目录是空的临时目录，快照作为额外可读目录传入，并关闭项目指令发现（Claude Code `--add-dir`，Codex `-c project_doc_max_bytes=0`），可被自动加载的配置（`CLAUDE.md`、`AGENTS.md`、`.claude/`、`.codex/`、`.mcp.json` 等）不放进快照目录，换成中性路径另放一份作为数据；配置目录（`CLAUDE_CONFIG_DIR`、`CODEX_HOME`）也指向临时目录，辅助会话写在这里并随之删除。
- Analyze 的用量由凭据转发端点按每个响应的用量字段记录，每个请求一条原始用量记录交给 `usage`，取消和失败的分析也计入；没收到最终用量就被中断的请求，输入按请求体估算，输出取转发时改写过的输出上限与可见文本估算中较大的一个（推理 token 不在流里），标为「估算（上限）」，之后能按请求 ID 查到真实用量时替换。
- 下面提到的 macOS 系统调用（`posix_spawn`、`PRIO_DARWIN_BG`、`setrlimit`、`proc_*`、`sandbox_check`、kqueue、内存压力、`hdiutil`）都由 `platform` 实现，本 crate 只调用它暴露的与平台无关的进程监护和磁盘映像接口（架构规则 6，[ADR 0019](../../docs/adr/0019.md)「影响」）。
- 命令行以后台优先级（`PRIO_DARWIN_BG`）运行，启动时用 `RLIMIT_NPROC` 把进程数上限设为当前用户进程数 + 64（内核在 fork 时拒绝；它按用户总数计，用户其他进程退出会放出余量，是已知限制，超出的成员由统计在 500 ms 内终止，清理不需要新建进程），每个进程用 `setrlimit` 限制 CPU 时间（macOS 没有不需要特权的内存配额，内存靠统计和系统内存压力限制：增长快时改为每 100 ms 统计，内存压力进入警告级别时立即终止全部分析）；全局同时最多 2 次分析，agent 只能写自己的 1 GB 工作映像（写满时 `ENOSPC`），每次开始分析前要求宿主卷剩余空间不少于所有已挂载映像还能增长的量（容量上限减当前实际占用）之和、新工作映像的 1 GB 与 2 GB 相加，不满足就排队，进行中低于 2 GB 全部终止；按沙箱识别这次分析的全部进程（`platform` 用 `sandbox_check` 检查本次临时目录与哨兵路径的权限，换进程组、`setsid` 或 double fork 都改不掉），统计它们的进程数、常驻内存和 CPU 时间合计（只对存活成员求和，每个成员自己的加上已回收子孙的 `ri_child_*_time`，每个进程只计一次），超限、超时、取消或结束时全部终止：先反复扫描并 `SIGSTOP` 直到没有还在运行的成员，再全部 `SIGKILL`。命令行的标准输出和标准错误边读边计数，单条 JSON 行上限 1 MB，合计 64 MB，超过时同样终止。结果显示前比较当前指纹和会话修订号，计算前后各读一次 worktree 修订号（`fs_watch`，先 `FSEventStreamFlushSync`），变了就重算，最多 3 次；显示后有新变化同样标为「基于较早的版本」；发布时带上检查时的修订号，在状态更新里比较仍相同才标为当前。启动命令行用 `posix_spawn` 加 `POSIX_SPAWN_CLOEXEC_DEFAULT`，只继承 0、1、2 三条管道；请求模板不含任何在模型服务端执行的工具（网页搜索、网页抓取、代码执行、文件检索、远程 MCP 与连接器），转发端点出现即拒绝；每次分析的合计上限（连接尝试 256 次、请求 64 个、请求字节 64 MB、每秒 4 个新连接）超出即关闭端点并终止分析；取消、超时或 agent 断开时中止上游请求并关闭与模型服务的连接；取密钥的辅助命令经监护进程启动，限时 30 秒、输出各 64 KB、超限终止全部子孙进程；出站请求头只由适配器和模型服务配置生成，认证、`Host`、组织与项目、API 版本和 beta 一类的头由 Lectern 覆盖写入，来访的模板外请求头和 hop-by-hop 头使请求被拒绝，命令行里也显式关闭（Codex 的网页搜索、apps、远程插件，Claude Code 的 WebSearch、WebFetch）。分析结果的缓存键包含分析流程的版本（提示词、校验、纠错、对账、启动参数、上限）。
- 测试启动命令行的代码时，在 PATH 最前面放一个假命令，记录参数、标准输入和工作目录，按夹具回放 JSON 行输出。

## 测试

不依赖 GPUI，在任何平台上都能编译和测试：

```sh
cargo check -p lectern-agents     # 只改本 crate 时最快的反馈
just test -p lectern-agents
```

- 单元测试写在模块旁的 `#[cfg(test)] mod tests`；结构化输出（解析结果、归因、diff）用 insta 快照验收，快照改动要在 PR 里逐个看过。
- 真实数据放 `tests/fixtures/`，先脱敏；格式随上游版本变化的，每个版本留一份样本。
